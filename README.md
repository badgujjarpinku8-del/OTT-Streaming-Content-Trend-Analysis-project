# OTT STREAMING CONTENT TREND ANALYSIS

**Python | SQL | Data Analytics | Google Colab**

## Project Overview
This project analyzes OTT streaming content using Python and SQL to understand content trends, genres, countries, ratings and release years.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL (SQLite)
- Google Colab

## Dataset Summary
- Total Titles: 40
- Movies: 21
- TV Shows: 19
- Countries: 8
- Genres: 20
- Release Years: 2017–2024

*Note: This is a sample practice dataset.*

## Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Converted date columns.
- Prepared data for analysis.

## Visualizations
1. Movies vs TV Shows
2. Top 10 Popular Genres
3. Content Release Trends by Year
4. Top 10 Content-Producing Countries
5. Content Rating Distribution
6. Movie Duration Distribution

## SQL Analysis
- Total content count
- Movies and TV Shows comparison
- Country-wise content analysis
- Genre analysis
- Rating distribution
- Year-wise content analysis

## Key Recommendations
1. Focus on frequently appearing genres.
2. Explore opportunities in underrepresented countries.
3. Analyze Movies vs TV Shows to improve content planning.

## Conclusion
This project demonstrates practical skills in Python, SQL, data cleaning, exploratory data analysis and data visualization.
